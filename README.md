# Medha

Medha is an early-stage AI assistant project with a FastAPI backend, browser frontend, and experimental local-language-model code.

## Run locally

Python 3.10+ is recommended.

```bash
python -m venv .venv
# macOS/Linux
source .venv/bin/activate
# Windows PowerShell
# .venv\\Scripts\\Activate.ps1

pip install -r backend/requirements.txt
uvicorn backend.main:app --reload
```

Open:
- Chat: http://127.0.0.1:8000/
- Medha Studio: http://127.0.0.1:8000/studio
- API health: http://127.0.0.1:8000/health
- API docs: http://127.0.0.1:8000/docs

## Medha Studio foundation

The first Studio foundation includes:
- A dedicated project workspace at `/studio`.
- A project brief input and starter project-plan display.
- Responsive project explorer, build-plan, preview and terminal panels.
- `POST /api/projects/plan` for a deterministic starter plan.

**Current limitations:** the project plan is rule-based, not generated by an LLM. Project files are not created yet. The preview and terminal panels are interface placeholders; no shell commands are executed. The existing `/chat` endpoint is still a connectivity placeholder and does not call a language model.

## Project layout

```text
backend/       FastAPI application
frontend/      Existing Medha chat interface
studio/        Medha AI Studio interface
medha_local_llm/ Experimental local model code
llm_from_scratch.py
transformer.py
```

## Safety direction

When code execution is introduced, run it in an isolated, resource-limited environment. Never execute arbitrary generated commands directly on the host or expose API keys to browser code.
