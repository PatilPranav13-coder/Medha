# Medha capability coverage

Target specialist tracks:
- Programming and app development: Python, C/C++, JavaScript/TypeScript, frontend/backend, API design, databases, testing, debugging, security and deployment.
- Software/system architecture: operating systems, networking, distributed systems, compilers, scalability, fault tolerance, CPU/GPU and accelerators.
- Research: paper reading, evidence extraction, experimental design, statistics, reproducibility, citations and uncertainty.
- Semiconductor/hardware: solid-state physics, devices, CMOS, VLSI, RTL, verification, FPGA, EDA, synthesis, timing, physical design, fabrication and materials.
- Core STEM: algebra, calculus, linear algebra, discrete maths, probability, statistics, mechanics, electromagnetism, quantum, chemistry and engineering.

## First pilot mixture hypothesis (pretraining only)
30% educational/scientific prose; 20% STEM/math; 20% programming/software; 15% semiconductors/computer architecture; 10% Indic languages; 5% general text. This is an experiment to measure, not a scientifically established optimum; label actual domain mix before sampling. SFT and preference data are later, separate stages.

## What the eight sources do not provide sufficiently
Add separately licensed official documentation, standards, textbooks, open-access papers, Verilog/SystemVerilog examples, RTL/verification tasks, OpenROAD/EDA flows, SPICE/device-physics datasets, app-development tutorials, architecture design reviews and reproducible engineering experiments. Do not assume web-scale data alone creates semiconductor expertise.

## Development progression
1. Foundation: math, physics, programming, algorithms and computer systems.
2. Builder: build tested apps, APIs, databases and secure deployments.
3. Architect: design scalable reliable systems and quantify trade-offs.
4. Researcher: synthesize sources, run experiments and document evidence.
5. Chip engineer: model devices, write RTL, verify, synthesize, time and physically design circuits.
